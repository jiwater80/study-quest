# 한윤재 전설이 되다 — 중1 2학기 완성 작전 🥄🎁

중학교 1학년 **2학기 국어·과학·사회·국사(역사)·수학**을 과목별 완성표로 공부하는 **게임형 학습 웹앱(PWA)** 입니다.
매일 유튜브로 배우고 **완료 체크**, 단원마다 **확인문제(10문항)** 와 과목 끝 **총정리(20문항)** 로 복습하며,
용돈(CNY, 元)을 모아 **목표 1000元** 달성이 최종 미션이에요.

## ✨ 기능
- **과목 탭 5개**: 국어 · 과학 · 사회 · 국사 · 수학 — 각 6일(총 30일)
- 날짜별 **유튜브 검색 버튼** + **완료 체크**
- **단원마다 확인문제 10문항** + 과목 끝 **총정리 20문항** — **채점하면 정답과 해설(💡)이 표시돼 바로 복습**
- **80점 미만이면 '영상 다시 보기'를 눌러야만 재도전** 가능(유튜브 재시청 유도)
- **80점(20문제 중 16개) 이상** 이어야 통과 · 용돈 지급, 미달이면 영상부터 다시 도전
- **목표 1000元 게이지** · 계급 진급(이등병→전설의 한윤재) · 만점 ⭐
- **역할 선택**: 한윤재(학생) / 엄마 · 아빠(보호자)

## 💾 저장 방식 (중요)
- 진행상황은 **기기(브라우저 localStorage)에 우선 저장**됩니다 — 한윤재 폰에서는 **안전하게 유지**되고 매일 지워지지 않아요.
- **3인 실시간(엄마·아빠가 다른 폰에서 실시간 보기)** 은 **무료 Firebase Realtime Database** 를 연결하면 켜집니다. (아래 참고)
- 이전에 쓰던 무료 임시 저장소(jsonblob)는 며칠 미접속 시 자동 삭제되어 사용을 중단했습니다.

### Firebase 연결(선택, 3인 실시간용)
1. https://console.firebase.google.com 에서 프로젝트 만들기(무료)
2. **Realtime Database** 만들기 → 위치 선택 → **테스트 모드**로 시작
3. 데이터베이스 URL 복사 (예: `https://xxxx-default-rtdb.firebaseio.com`)
4. `index.html`(또는 소스) 상단의 `var FIREBASE_DB = "";` 에 그 URL을 넣기
   → 저장하면 3인 실시간 동기화가 켜집니다.

## 🧩 과목 구성 (중1 2학기 · 미래엔·비상 계열 기준)
- **국어:** 품사 · 어휘 · 주장하는 글 · 매체 읽기 · 토의와 토론
- **과학:** 기체의 성질 · 물질의 상태 변화 · 빛과 파동
- **사회:** 개인과 사회 · 문화의 이해 · 정치와 민주주의 · 정치 과정 · 일상생활과 법
- **국사(한국사):** 선사·고조선 · 여러 나라의 성장 · 삼국의 성립과 발전 · 삼국의 문화 · 남북국(통일 신라·발해)
