# 한윤재 전설이 되다 — 중1 1학기 완성 작전 🥄🚲

중학교 1학년 **1학기 국어·과학·사회**를 14일 완성표로 따라잡는 **게임형 학습 웹앱(PWA)** 입니다.
매일 유튜브로 배우고 **완료 체크**, 단원이 끝나는 날 **확인문제(퀴즈)** 로 복습하며,
용돈(CNY, 元)을 모아 **자전거(목표 3000元)** 를 사는 것이 최종 도전 목표예요.

## ✨ 기능
- **과목 탭**(국어 / 과학 / 사회) · 각 과목 **14일 완성표**
- 날짜별 **유튜브 검색 버튼** + **완료 체크**(자동 저장)
- 단원 확인문제·모의테스트 **각 10문항** — **채점하면 정답이 표시돼 바로 복습**
- **80점(10문제 중 8개) 이상** 이어야 통과 · 용돈 지급, 미달이면 재도전
- **자전거 3000元 목표 게이지** · 한윤재 계급 진급 · 만점 ⭐
- **금액·목표 수정**으로 용돈 단가·목표액 조절, 이름 변경
- 진행상황은 브라우저(localStorage)에 저장 — **오프라인에서도 동작**(설치형 PWA)

## 📲 앱처럼 설치하기
1. 아래 주소를 폰/PC 브라우저로 엽니다.

   - **안드로이드(Chrome):** 메뉴(⋮) → **앱 설치 / 홈 화면에 추가**
   - **PC(Chrome/Edge):** 주소창 오른쪽 **설치** 아이콘

## 🧩 단원 구성 (2015 개정 · 중1 1학기)
- **과학:** 지권의 변화 · 여러 가지 힘 · 생물의 다양성 · 기체의 성질 · 물질의 상태 변화
- **사회①(지리):** 내가 사는 세계 · 세계의 기후 · 지형 · 문화 · 자연재해 · 자원과 갈등
- **국어:** 시 · 소설 · 문법(음운) · 읽기(설명) · 화법·쓰기

> 국어·사회 단원 순서는 출판사(미래엔·비상·천재·창비 등)마다 조금 다를 수 있어요. 교과서 목차와 맞춰 참고하세요.

## 🛠 기술
- 순수 **HTML/CSS/JavaScript** 단일 페이지 — 빌드 도구·서버 불필요
- **PWA**: `manifest.webmanifest` + `sw.js`(오프라인 캐시)
- 데이터 저장: 브라우저 `localStorage` (키: `chwisabyeong_plan_v4`)
